# GrandStay luxury frontend

Open `index.html` to view the new hotel website. No npm or build step is required.

The original `js/app.js`, `css/style.css`, and `README.md` are unchanged. The original six management modules remain available through **Manage Hotel**, **Explore rooms**, and **Plan a reservation**. Use **Hotel website** to return to the homepage.

New presentation files: `css/luxury.css` and `js/experience.js`. The homepage markup was added to `index.html` without removing the original management interface.

Hotel photos use external Unsplash image URLs and require an internet connection. Room names and experience copy are illustrative presentation content; prices, availability, and reservation confirmation come from the existing backend. The homepage does not claim to submit or confirm a booking. Start your Spring Boot backend at `http://localhost:8080` for management functions, as described in the original README.

The uploaded project includes only the frontend; no backend files were supplied or changed. Backend availability and end-to-end API operations must be verified with your running Java application.
