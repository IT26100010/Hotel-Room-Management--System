# GrandStay Frontend

## Run using VS Code Live Server (recommended)
1. Open this `frontend` folder in VS Code.
2. Right-click `index.html` and select **Open with Live Server**.
3. Make sure the Spring Boot backend is already running on `http://localhost:8080` from IntelliJ.

`js/app.js` points to `http://localhost:8080`. Backend CORS is configured for Live Server's common localhost/127.0.0.1 ports 5500 and 5501.
